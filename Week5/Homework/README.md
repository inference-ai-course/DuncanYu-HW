# Week 5 – Hybrid Search Implementation

This week focused on implementing hybrid search combining vector search (FAISS) with traditional text search (BM25/FTS) for improved retrieval performance.

## Tasks

- Implement hybrid search combining FAISS vector search and BM25 text search
- Create SQLite FTS (Full-Text Search) database for BM25 scoring
- Develop score normalization and fusion algorithms
- Build FastAPI interface for hybrid search functionality
- Optimize search ranking with configurable alpha weighting
