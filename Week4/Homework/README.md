# Week 4 – Vector Search & RAG Pipeline

This week focused on building a complete RAG (Retrieval-Augmented Generation) pipeline using vector search with FAISS and document processing.

## Tasks

- Build a document scraping and processing pipeline
- Implement text chunking and embedding generation
- Create FAISS vector index for semantic search
- Develop FastAPI web interface for search functionality
- Process ArXiv papers for the knowledge base
