## 📋 Weekly Overview

### **Week 1: MCP & Ollama Fundamentals**
- **Focus**: Model Context Protocol (MCP) integration and local LLM deployment
- **Technologies**: Claude MCP, Ollama, OpenAI API, Gradio
- **Key Projects**: Browser automation, GitHub integration, Notion API, local LLM setup

### **Week 2: Data Collection & Processing**
- **Focus**: OCR, web scraping, and data extraction techniques
- **Technologies**: Tesseract OCR, Trafilatura, PDF processing, ASR
- **Key Projects**: Multi-modal data extraction, LLM performance comparison

### **Week 3: Voice Research Agent**
- **Focus**: End-to-end voice-enabled research assistant
- **Technologies**: FastAPI, OpenAI Whisper, Hugging Face, Coqui TTS
- **Key Features**: Voice input/output, live audio processing, web integration

### **Week 4: Vector Search & RAG Pipeline**
- **Focus**: Retrieval-Augmented Generation implementation
- **Technologies**: FAISS, sentence transformers, FastAPI, ArXiv processing
- **Key Projects**: Document indexing, semantic search, web interface

### **Week 5: Advanced Search & Model Training**
- **Focus**: Advanced search techniques and model fine-tuning
- **Technologies**: FAISS + BM25, SQLite FTS, LoRA fine-tuning
- **Key Projects**: Hybrid search fusion, automated training pipelines

### **Week 6: Voice Research Agent v2**
- **Focus**: Enhanced voice interaction system with modular architecture
- **Technologies**: FastAPI, OpenAI Whisper, Coqui TTS, configurable LLMs
- **Key Features**: Real-time speech processing, cross-platform compatibility, flexible model backends

### **Week 7: Synthetic Data Generation & Fine-tuning**
- **Focus**: Automated synthetic dataset creation and model fine-tuning with QLoRA
- **Technologies**: OpenAI API, Hugging Face Transformers, Unsloth, QLoRA
- **Key Projects**: Research paper Q&A generation, efficient fine-tuning pipelines, model evaluation
